# 2級の大問データの形（`source-2kyu/<回>/q<番号>.json`）

設計: `docs/superpowers/specs/2026-10-31-kyu2-design.md`。検査: `python3 scripts/check_kyu2.py source-2kyu`。

```jsonc
{
  "round": 38,              // 回
  "no": 1,                  // 大問の番号（1〜5）
  "points": 20,             // 配点（問題文の「（20 点）」）
  "title": "仕訳",          // 短い名前（仕訳／計算／原価計算／精算表 など。中身で決める）
  "problem": [ /* 大問の共通の文と資料。Block の並び */ ],
  "parts": [ /* 答える欄。Part の並び。問題の順 */ ]
}
```

## Block（読むだけの部分）

- `{ "t": "p", "text": "..." }` 段落。1文ずつでなく、原本の段落ごと。番号つきの箇条（(1)、①）も1項目1段落でよい
- `{ "t": "table", "caption": "未成工事支出金（単位：円）", "rows": [["工事番号","No.301","No.302"],["材料費","86,000","236,000"]] }` 資料の表。1行目は見出し。数字は原本どおりカンマつきの文字
- `{ "t": "choices", "title": "勘定科目群", "items": [["Ａ","現金"],["Ｂ","当座預金"]] }` 勘定科目群・用語群。記号は原本の全角のまま

## Part（答える欄）

共通: `"label"`（「(1)」「問１」「問３ 記号」など、解答用紙の見出し）、`"prompt"`（その欄の小問の文。大問の共通の文に含まれるなら省略可）。

- 仕訳1題
  ```json
  { "kind": "journal", "label": "(1)", "prompt": "株主配当金…支払った。…",
    "debit": [["Ｑ", 5000000]], "credit": [["Ｂ", 4000000], ["Ｌ", 1000000]] }
  ```
  記号は同じ大問の `choices` にある物だけ。借方の合計＝貸方の合計
- 数の1欄
  ```json
  { "kind": "number", "label": "(1)", "prompt": "…内部利益は￥【　】である。", "prefix": "￥", "suffix": "", "a": 10800 }
  ```
  空欄は `【　】` で書く。単位が後ろなら `"prefix": "", "suffix": "年"`。小数もそのまま数で
- 記号の1欄
  ```json
  { "kind": "symbol", "label": "問３ 記号", "prompt": "借方差異ならＡ、貸方差異ならＢ", "choices": ["Ａ","Ｂ"], "a": "Ｂ" }
  ```
  用語群から選ぶ欄は `choices` に記号を全部並べる
- 表（工事別原価計算表・部門費振替表・精算表など、解答用紙の表）
  ```json
  { "kind": "table", "label": "精算表", "title": "精算表（単位：円）",
    "head": [["勘定科目","残高試算表","","整理記入","","損益計算書","","貸借対照表",""],
             ["","借方","貸方","借方","貸方","借方","貸方","借方","貸方"]],
    "rows": [
      ["現金", "20,300", "", {"a": []}, {"a": []}, {"a": []}, {"a": []}, {"a": [20300]}, {"a": []}],
      ["未成工事支出金", "362,400", "", {"a": [800, 3200]}, {"a": [2140, 109040]}, {"a": []}, {"a": []}, {"a": [257200]}, {"a": []}]
    ] }
  ```
  - 文字の欄（`"20,300"`・`""`・`"―"`）は解答用紙に印刷済みの物。打ち込まない
  - `{"a": [...]}` は打ち込む欄。中身は正しい答えの金額。1つの欄に金額が複数あるなら全部並べる（採点は合計で比べる）。答えが空の欄は `{"a": []}`
  - 解答用紙で「―」が印刷された欄は `"―"`
  - 表の中で勘定科目の記号を書く欄（勘定記入の「借方科目」「貸方科目」など）は `{"s": "Ｂ"}`。記号は同じ大問の `choices` にある物だけ。表の見出しそのものが答え（「どの勘定か」の記号）の時は、表の直前に `symbol` の part を置く
  - 合計の行・当期純利益の行も、解答用紙にあれば行として入れる。科目名の欄が印刷済みなら文字、打ち込む科目名（「当期（純利益）」の括弧など）は文字のままでよい
  - head は1〜2行。列の数はすべての行で同じ

## 守ること

- 金額・数・記号は原本（公式の問題・解答用紙）と TAC の解答のとおり。推測で埋めない。読めない所は止めて報告
- 答えは TAC の解答（`*_sokuhou.pdf`、無ければ `*_kaisetu.pdf` の中の解答）から写す
- 問題文は省略しない・言い換えない（数字・条件を落とさない）。改行の位置と空白は整えてよい
