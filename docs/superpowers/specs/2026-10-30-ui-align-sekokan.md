## 作るもの

### 1. 見た目の土台
- `src/index.css` に施工管理ドリルと同じ CSS 変数（--bg --sf --el --hair --ink --ink2 --ink3 --acc --acc-soft --acc-line --ok --ok-soft --ng --ng-soft --r --rs --shadow）を置き、画面は全部これを使う。Tailwind の emerald/lime/red の色クラスは使わない（Tailwind は余白・並びだけに使ってよい）。
- 色は後で3案（施工管理と同じ赤茶／緑／青）を見比べるので、アクセントの3つ（--acc --acc-soft --acc-line）は `:root[data-accent="green"]`・`:root[data-accent="blue"]` で差し替えられるようにする。既定は赤茶。緑は #2f6b4f / #edf4ef / #b9d3c2、青は #2f5f9e / #edf2f9 / #b7c9e2。画面に切り替えのボタンは作らない（確認用。URL の `?accent=green` でだけ切り替わる）。
- ダークモードを全部消す（`dark` の state・ボタン・`dark:` クラス・localStorage の `kenkei-drill.dark`）。
- 書体: BIZ UDPゴシック（Regular・Bold）と BIZ UDゴシック（数字用・Regular・Bold）を、画面で使う文字だけに絞って woff2 にし、`public/fonts/` に置いて `@font-face` で読む。絞り込みは `scripts/subset-fonts.py`（fontTools。`src/` の .ts/.tsx の文字＋ASCII＋ひらがな・カタカナ全部＋全角数字・記号）。数字用は ASCII の数字と「:/.%-」だけでよい。`package.json` の `build` の前に走るようにする（`prebuild`）。元の TTF はお手本のフォルダから読む（リポジトリにコピーしない）。OFL.txt は `public/fonts/` にコピーする。
- 数字（日数・分・点・時計）は等幅の数字（`.mono` クラス・BIZ UDゴシック）。

### 2. ホーム（`Today.tsx` を作り直す。お手本 home-light の並びのまま）
1. 見出し: 「建設業経理士ドリル」（太字・大）、下に「建設業経理士1級の過去問（第◯〜◯回）」（index の mock でない回の最小〜最大）。右上に小さなバッジ「1級・公式過去問」（--acc の枠線・文字）。
2. 白いカード（上下2段・間に線）:
   - 上段: 左「試験日まで」大きな日数＋「日」、その下「2027年3月14日(日) 実施」（index.examDate から曜日つきで作る）。右「連続学習」＋日数。
   - 下段: 「今日の学習」と右に「X / 目標 分」（X は --acc 色）。進み具合の棒。案内文（例「今日は復習の時期が来た大問 a題、まだ解いていない大問 b題。」a・b が0の時は出し分ける。全部終わっていたら「今日の分は終わりました。科目別で続けられます。」）。ボタン「今日の学習を始める」（全幅・--acc・白文字）。押すと今の orderTodayQuestions の順のまとまりで始める。
3. 「学習モード」見出し＋2列のカード（お手本の .mode と同じ形。題・説明・--acc 色の件数）:
   - 復習｜復習の時期が来た大問｜n 題
   - まだ解いていない大問｜一度も解いていない大問｜n 題
   - 科目別｜科目を選んで解く｜全3科目
   - 模試｜第39回を本番と同じ90分で｜3 科目（mock の回の科目数）
4. 「学習状況」見出し＋白いカード: 科目ごとに「予想点（初見の得点から）」の行と棒。棒に70点の位置の印。右に「◯点」か、初見で解いた大問が0なら「まだ解いていない」。上に「解いた大問 x／y題」。模試の点があれば科目の行に「模試 ◯点」。その下に「直近7日の学習時間」（日付と分の行）。今の Stats 画面の中身をここへ移す。
5. 「設定」見出し＋白いカード: 1日の目標（分）の入力（お手本の試験日の設定と同じ形）。
6. フッター: 「記録を書き出す」「記録を読み込む」「鍵を削除してロック」（--acc 色の文字のリンク風。鍵の削除は確認の窓を出す）。その下に小さい文字で「問題: 一般財団法人 建設業振興基金 公表の試験問題（第◯〜◯回）。解答・解説: TAC 解答速報。学習の記録はこの端末のブラウザにだけ保存されます。」

### 3. 科目別の画面（お手本 cats と同じ形）
左上「←」と題「科目を選択」。科目ごとの白いカード: 科目名／「n題中 a題解いた・b題は復習の時期」／「解く →」。押すとその科目の mock でない大問を「復習の時期が来た物→まだ解いていない物→残り（新しい回から）」の順で並べたまとまりで始める。

### 4. 模試の画面（お手本 exam-pick と同じ形）
左上「←」と題「模試」。説明文「第39回を本番と同じ90分で通して解きます。終わったら解答と解説を見て、まとめて自己採点します。普段のドリルには出しません。」科目ごとのカード「第39回 財務分析／5題・90分／始める →」と記録済みの点。始めた後の流れ（タイマー・まとめて自己採点・保存）は今の Mock.tsx の動きを変えず、見た目だけ変える。タイマーの帯は赤でなく白い面に --acc の文字。

### 5. 問題の画面（お手本 quiz-wrong と同じ形）
- 上の帯（白・下に線）: 左に進み具合の細い棒と「i / N」、右に「×」の四角いボタン（押すと今の pauseStudy してホームへ）。
- チップ: 科目（--acc-soft 地・--acc 文字）、「第◯回 大問◯」（--el 地）、「◯点」。右端に経過時間（等幅）。
- 問題の画像は白い面・細い線・角丸 --r の中に。「画像をタップすると大きく表示します」の小さい案内。
- 記号の小問: お手本の選択肢と同じ白い枠のボタン。選ぶと --acc の枠と --acc-soft の地。答えを見た後は正しい記号を --ok、選んで違った記号を --ng の色に。
- 「解答を見る（a/b）」全幅の --acc ボタン。
- 解答・解説の画像はお手本の解説の箱と同じ（白い面・左に --acc の太い線・見出し「解答」「解説」）。
- 自己採点: 白いカード。満点／7割／半分／0点の4つのボタン（点数つき）と数値の入力。押したら記録して、まとまりに次があれば次の大問、無ければ結果画面へ。

### 6. 結果画面（お手本 results と同じ形）
「おつかれさまでした」、下にまとまりの名前（「今日の学習」「復習」「科目別：財務分析」など）。円のグラフ（得点の合計÷配点の合計の％、中に「得点 / 配点」）。タイル3つ: 解いた大問・連続学習（日）・今日の学習（分）。案内文: 70%以上なら「合格ラインの70%を超えました。この調子で続けましょう。」未満なら「70%未満の大問は明日もう一度出ます。」ボタン「続けて学習する」（今日の学習のまとまりで始める）・「ホームに戻る」。

## 計算（`src/lib/` に置き、vitest で先にテストを書く。RED を見てから実装）
- `studyStreak(sessions, today)`（records.ts）: 学習した日（studyMinutesByDay で1分より多い日）が今日か昨日から何日続いているか。今日まだ学習していなくても昨日まで続いていればその日数。2日以上あいていたら0。日の区切りは今と同じ端末の0時。境目（ちょうど昨日・一昨日）でテストする。
- `queueFor(mode, questions, records, now, subject?)`（schedule.ts）: mode は "today"（今の orderTodayQuestions と同じ）・"review"（期限が来た物だけ）・"unsolved"（記録が無い物だけ）・"subject"（その科目の、期限→未着手→残り）。全部 mock を除く。並びは今の sort と同じ（科目→新しい回→大問番号）。
- `countModes(questions, records, now)`: { review, unsolved }。
- 結果画面の％は `sessionScore(results)`（得点合計／配点合計、配点0なら0）。

## 変えないもの
- 記録の形（localStorage のキー・RecordsState・書き出し JSON）。今の記録がそのまま読めること。
- 復号・データの読み込み・学習時間の数え方（60分で打ち切り・画面を離れたら止める）・予想点の出し方（初見だけ）・復習の間隔・模試の採点の保存。
- `src/lib/` の既存のテストは全部通ったまま。
