# 建設業経理士1級ドリル 設計（2026-10-20）

## 目的
CEO個人が 2027-03-14（日）の第40回 建設業経理士検定 1級（財務諸表・財務分析・原価計算）に向けて、スマホで毎日回す過去問ドリル。CEO専用。公開しない。

宅建ドリルの振り返り（`takken-drill/docs/retrospective/2026-10-18-r8-honshiken.md`・`2026-10-19-mastery-metric-research.md`）の教訓を最初から入れる。
- 同じ問題の解き直しで正答率が水増しされた（ドリル97%→本番64%）→ 予想点は**初見の解答だけ**で出す。
- 一問一答が効いた → 記号で答える小問（語群の穴埋め・Ａ/Ｂ・Ｔ/Ｆ）は1つずつ入力して自動採点する。
- 学習時間の記録が一部しかなかった → 問題を開いてから自己採点するまでの時間を日ごとに残す。
- 模試を解いていない年度で受ける → 第39回（2026-09-13）は模試用に温存し、普段のドリルに出さない。

## 原本と非公開の守り方
- 問題: 建設業振興基金の公式PDF（第34〜39回）。https://www.keiri-kentei.jp/exam/past/index.html 。公式は模範解答を出していない。
- 解答・解説: TAC が公開している解答速報・解説PDF。https://www.tac-school.co.jp/kouza_kensetu/sokuhou.html （「無断転載・転用を禁じます」）。
- 表示は**原本PDFを大問ごとに切り出した画像**。書き写さない（原本主義）。
- データ束はすべて AES-GCM で暗号化して置く。最初に1回パスワードを入れた端末だけが読める。リポジトリ・URLに読める形で載るのはアプリのコードと、TACの文章を含まない目次（`data/index.json`）だけ。
- 原本PDF（`source-pdfs/`）と平文の中間生成物（`build/`）はコミットしない。

## データの受け渡し形式（パイプライン → アプリ）
`public/data/index.json`（平文）:
```json
{ "version": 1, "examDate": "2027-03-14",
  "exams": [ { "id": "39b", "round": 39, "date": "2026-09-13", "subject": "zaibun",
               "mock": true, "questions": [ { "no": 1, "points": 20 } ] } ] }
```
- subject: `zaihyou`（財務諸表）/ `zaibun`（財務分析）/ `genka`（原価計算）。表示順と学習の優先順は zaibun → zaihyou → genka。
- `mock: true` は第39回だけ。

`public/data/{id}.bin`（暗号化）: バイト列 = salt(16) ‖ iv(12) ‖ AES-256-GCM 暗号文。鍵 = PBKDF2-SHA256(パスワード, salt, 200000回, 256bit)。復号すると UTF-8 JSON:
```json
{ "id": "39b", "questions": [
  { "no": 2, "points": 15,
    "problem": ["data:image/webp;base64,..."],
    "answer":  ["data:image/webp;base64,..."],
    "explain": ["data:image/webp;base64,..."],
    "items": [ { "label": "1", "answer": "サ", "choices": ["ア","イ", "…", "チ"] } ] } ] }
```
- `items` は記号で答える小問だけ。無い大問は空配列。
- 画像は上から順に縦に並べて表示する（大問が複数ページにまたがると複数枚）。

## アプリ（Vite + React + TypeScript + Tailwind、静的SPA、GitHub Pages `/kenkei-drill/`）
1. **鍵の入力**: 初回だけパスワード入力。index の先頭の束で復号を試し、成功したら導出した鍵を localStorage に保存。失敗なら「パスワードが違います」。
2. **今日やる**（ホーム）: 試験日までの残り日数、今日の学習時間／目標（既定60分・設定で変更）、次にやる大問。出す順は ①復習期限が来た大問 ②まだ解いていない大問（zaibun→zaihyou→genka、各科目は新しい回から）。mock の回は出さない。
3. **大問を解く**: 問題画像（タップで拡大）＋経過時間。items があれば記号ボタンで1つずつ答える。「解答を見る」で items を自動採点し、解答画像と解説画像を出す。自己採点で得点（0〜配点、ボタン: 満点／7割／半分／0／数値入力）を記録。items だけの大問は自動採点の割合×配点を初期値にする。
4. **復習の間隔**: 大問ごと。得点率70%以上なら 3→7→14→30日と広げる。70%未満なら翌日。
5. **成績**: 科目ごとの予想点 =（初見で解いた大問の得点合計 ÷ その配点合計）×100。初見で解いた大問数／全大問数も出す。合格ライン70点を並べる。模試の点があれば横に出す。科目ごとの学習時間の合計、日ごとの学習時間。
6. **模試**: 第39回の科目を選び、90分のタイマーで5題を通しで解く→最後にまとめて自己採点→模試の点として記録。
7. **記録**: すべて localStorage。設定画面に「記録を書き出す／読み込む」（JSON）。
8. 見た目: スマホ幅前提、ライト／ダーク両対応、文字は日本語。
